# DoAide Colors

Free color tools for designers and developers at [colors.doaide.com](https://colors.doaide.com).

## Features

- **Color Palette Generator** — Generate harmonious 5-color palettes (complementary, analogous, triadic, split-complementary, tetradic)
- **Color Picker** — Advanced picker with HEX, RGB, HSL, CMYK output
- **Gradient Generator** — CSS gradients (linear, radial, conic) with live preview
- **Contrast Checker** — WCAG AA/AAA accessibility checker
- **Image Color Extractor** — Extract dominant colors from images
- **Color Converter** — Convert between HEX, RGB, HSL, CMYK
- **Tailwind Color Finder** — Find closest Tailwind CSS color class
- **Brand Colors** — Curated palettes from Google, Apple, Meta, Flipkart, Zomato, etc.
- **CSS Shadow Generator** — Box shadow with live preview
- **Font Pairing** — Google Font pairings with live preview

## Tech Stack

- React + Vite
- Tailwind CSS 3.4
- Frontend only — all processing client-side

## Development
